# Horário de funcionamento

![Tela de horário de funcionamento](/img/manager/admin/horario-funcionamento.png)

Em **Horário de Funcionamento**, configure os dias e horários em que a unidade atende. Esse horário é a base usada para calcular os horários de consulta disponíveis no app do paciente.

## Configurando o horário semanal

1. Se sua conta administra mais de uma unidade, selecione a unidade desejada no topo da página.
2. Para cada dia da semana, marque **Fechado** se a unidade não atende naquele dia.
3. Nos dias em que atende, preencha os horários de **Abertura** e **Fechamento**.
4. Toque em **Salvar horário**.

:::note
O horário de abertura precisa ser sempre anterior ao de fechamento — se algum dia estiver inconsistente, a tela avisa qual dia corrigir antes de salvar.
:::

## Relação com os exames

A disponibilidade de horários para agendamento de exames, configurada em [Disponibilidade de exames](./disponibilidade-exames.md), deve respeitar este horário de funcionamento da unidade.
