# Gestão da unidade de saúde

{/* IMG: tela de dados da unidade */}

## Dados da unidade

Em **Unidade**, cadastre/atualize:

- Nome, endereço e informações de contato
- Especialidades atendidas

## Próximos passos

Depois de cadastrar os dados da unidade, configure os dias e horários de funcionamento em [Horário de funcionamento](./horario-funcionamento.md) — essa é a base usada para gerar os horários disponíveis de agendamento dos exames.
