# Perfil e conta

O administrador não tem uma página própria de perfil. No rodapé do menu lateral, em qualquer tela do painel, fica um cartão compacto com:

- Seu nome e o rótulo **Administrador**.
- Um botão de alternância de **tema claro/escuro**.
- Um botão de ajuda (**Como usar o Manager**), que abre este manual em uma nova aba.
- O botão **Sair**, para encerrar a sessão.

:::note
Não há formulário de edição de dados pessoais para o administrador nesta versão do Manager. A gestão de dados da equipe (profissionais e recepcionistas) é feita em [Profissionais](./profissionais.md) e [Recepcionistas](./recepcionistas.md).
:::
