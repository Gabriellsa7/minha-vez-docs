# Exames

{/* IMG: tela de exames do profissional */}

Em **Exames**, veja os exames dos pacientes que você atendeu, enviados pelos profissionais responsáveis pela realização (laboratório, radiologia etc.).

## Consultando exames de pacientes

- A tela lista os exames disponíveis para os seus pacientes atendidos.
- Toque em um exame para abrir os detalhes e visualizar o PDF do resultado.

Se ainda não houver nenhum exame disponível, a tela mostra o aviso "Nenhum exame disponível para os seus pacientes ainda."

:::note
O envio do arquivo do exame é feito pelo profissional de exame responsável, em [Enviar resultado](./exames-profissional-envio.md). Esta tela é apenas de consulta.
:::
